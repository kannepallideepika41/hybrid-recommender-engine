# Hybrid E-Commerce Recommendation & Ranking Engine

A production-grade two-stage recommendation architecture:
1. **Candidate Retrieval Layer**: Content-based similarity retrieval across catalog titles and categories.
2. **Re-Ranking Layer**: High-precision LightGBM classification optimizing for user session click-through rate (CTR).

## Tech Stack
- Python, LightGBM, Scikit-learn, Pandas, NumPy, Streamlit, Git, GitHub
